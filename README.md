# E-commerce Data Analysis

## Project Overview
This project analyzes e-commerce sales data to understand sales trends, sales channel performance, product category performance, and product profitability using SQL and Python.

## Objectives
- Analyze yearly and monthly sales trends.
- Compare sales performance across different sales channels.
- Identify high-performing product categories.
- Find the top 10 best-selling products.
- Explore business opportunities using data-driven insights.

## Tools & Technologies
- **MySQL** — data querying and aggregation
- **Python** — data analysis
- **Pandas** — data manipulation
- **Matplotlib** — data visualization
- **Seaborn** — statistical visualization
- **Jupyter Notebook** — analysis environment

## Dataset
- **Source:** [E-Commerce Sales Analytics Dataset — Kaggle Notebook](https://www.kaggle.com/code/sometimessubodh/the-e-commerce-story-decoding-138k-orders/input)
- **Files used:** `ecommerce_sales_customer_analytics_150k.csv`, `customer_master.csv`, `order_items.csv`, `product_catalog.csv`, and `dataset_statistics.csv`.

## Business Questions
1. What is the yearly sales trend?
2. Which sales channel generates the highest revenue?
3. Which product categories generate the highest sales?
4. Which are the top 10 best-selling products?
5. How do sales change month by month?

## Key Findings
- Yearly sales remained relatively stable between 2021 and 2025, with lower total sales in 2025 than in 2021.
- Mobile App generated the highest sales among the analyzed sales channels.
- Electronics generated the highest sales and profit among the product categories.
- Sports & Outdoors had the highest quantity sold among the product categories.
- The top-selling individual product had 904 units sold.

## Project Workflow
1. Loaded e-commerce data from MySQL into Pandas.
2. Checked missing values, duplicate records, and data types.
3. Analyzed business questions using SQL.
4. Created visualizations using Matplotlib and Seaborn.
5. Documented findings and business recommendations.

## Repository Contents

## Conclusion
This project demonstrates the use of SQL and Python for exploratory data analysis, business performance evaluation, and visualization of e-commerce sales data.
